SPS-VeriSpec Pipeline Guide

The project has one conservative trusted path and several optional research lanes. The workbench shows how facts, Datalog relations, generated tests, validation results, and review-only findings connect without treating every discovered relation as an executable test.

The Core Path

AST factsDataclasses, functions, calls, fields, literals, boundaries.
Souffle rulesSchema, effect, deduction, test-target, semantic layers.

Test familiesOnly high-confidence executable oracle families are emitted.
ValidationGenerated pytest suite runs against the target checkout.
ReviewLower-confidence or unsupported relations stay quarantined.
Trusted default

Static Analysis Lane

This is the main route: extract Python facts, run the static Souffle rule set, generate conservative pytest families, then validate. It is deterministic and is the best baseline for demos and regression runs.

Entry point: tools/evaluate_pipeline.py

Optional

Combined or LLM Rule Lane

The LLM-assisted rule layer can propose or run alternate Datalog rules, but its findings are provenance-tainted and should be compared against the static baseline. Use it to explore rule coverage, not to silently promote tests.

Switch: --rule-mode llm or --rule-mode combined

Quarantined

Oracle Candidate Lanes

Invariant mining, plateau candidates, local Qwen semantic assist, and metamorphic findings can produce useful review records. Passing validation can make something a promotion candidate, but failures are treated as design conflicts or findings until reviewed.

Switches: --with-invariants, --with-plateau, --with-local-llm-semantic-assist, --with-static-metamorphic

Choosing a Route

Goal Use Why
Repeatable public demo Checked-in replay artifacts Fast, deterministic, and independent of target dependency setup.
New target baseline Static lane with --skip-mutation first Separates extraction/rule/test-generation problems from slower evaluation.
Dataclass-heavy target Schema, constructor, conversion-profile families These are the most portable executable oracles today.
Large dependency-heavy target Bounded slice plus disposable validation venv Prevents import skips and avoids polluting the main development environment.
Explore missing relation coverage Generator coverage and LLM/combined comparison Shows discovered-vs-emitted gaps without pretending every gap has a safe oracle.
Supply semantic hints for hard-to-generate tests Plateau candidates plus local Qwen semantic assist Uses a local model to propose quarantined pytest witnesses grounded in relation rows and facts.
Look for semantic bugs Metamorphic or invariant lanes Useful for review-only findings; they need human interpretation before promotion.

Replay vs Live

Replay is the public default. Live runs are local-only and allowlisted because target dependencies, runtime, and project size vary by case.

Tests vs Findings

A generated test family means SPS-VeriSpec has a conservative executable oracle. A finding means the relation is useful evidence, but not trusted-suite truth yet.

Local LLM Assist

The local model lane uses the same manifest and validation path as other quarantined candidates. It can suggest semantic witnesses, but it cannot promote itself into the trusted suite.

Raw Files

Raw generated test files are secondary artifacts. The primary demo surface is the graph connecting source facts, relation families, emitted tests, validation, and findings.
